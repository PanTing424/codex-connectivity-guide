## 订阅前准备

1. 确认准备长期使用的 ChatGPT 账户及登录方式。
2. 在账户设置和设备的订阅管理页面检查是否已有有效订阅。
3. 使用官方网站或官方应用，核实应用发布者。
4. 准备购买渠道支持的支付方式，并核对地区、币种和账单信息。
5. 记录套餐名称、付款金额、计费周期和预计续费日期。

请使用真实、适用的账户及账单资料。银行卡能否支付，应以发卡行、购买渠道和实际交易结果为准，不按银行卡品牌推定一定可用。

## 选择套餐

打开账户内的套餐或升级页面，比较以下内容：

| 项目 | 需要核对的内容 |
| --- | --- |
| 套餐名称 | 确认最终购买的是目标套餐及档位 |
| 功能 | 检查所需模型、工具和使用方式是否包含在内 |
| 用量 | 查看适用的限制、重置时间和额外用量选项 |
| 价格 | 核对币种、税费与最终扣款金额 |
| 周期 | 核对本次购买覆盖的时间及后续续费安排 |

如页面显示 Pro 5x、20x 等档位，应阅读该档位的具体说明，不将倍率直接等同于所有功能的固定次数，也不据此推算价格。

套餐和用量说明可能调整，购买前重新查阅 [OpenAI 官方定价说明](https://learn.chatgpt.com/docs/pricing)。

## 选择购买渠道

可以先检查网页和手机应用中实际提供的购买入口。选择一个渠道完成购买，并保存对应订单。

| 入口 | 购买前检查 |
| --- | --- |
| 网页 | 当前登录账户、目标套餐、支持的付款方式和账单信息 |
| Android 应用 | ChatGPT 登录账户、Google Play 账户及购买确认页面 |
| iPhone 或 iPad 应用 | ChatGPT 登录账户、Apple 账户及购买确认页面 |

在手机上操作时，需要同时核对应用中的 ChatGPT 账户与商店账户，避免将订阅买到错误账户。

如果计划使用商店余额或礼品卡，先核对商店对地区、余额用途和订阅付款的要求，再决定是否充值。不要在未确认适用性的情况下预存大额余额。

## 完成付款与确认权益

1. 在目标账户内选择套餐。
2. 阅读付款确认页面，核对本次金额、周期、续费价格和生效时间。
3. 完成购买渠道要求的付款验证。
4. 保存订单号、收据与扣款记录。
5. 返回 ChatGPT，检查套餐状态和目标功能。
6. 如权益未显示，按后文排查，先核对订单状态再决定下一步。

银行扣款通知、商店订单状态和账户权益是三个需要分别核对的项目。出现异常时不要连续重复购买。

## 升级与变更套餐

从当前订阅的管理入口查看可用变更选项，在确认前检查：

- 新套餐何时生效；
- 本次需要支付多少费用；
- 原套餐剩余时间如何处理；
- 下次续费日期是否变化；
- 新套餐的用量规则。

没有明确显示的退款、抵扣或额度变化，不自行假定。保留升级确认页面和收据，便于后续核账。

跨渠道变更前，先查清原订阅是否仍在续费、何时到期，以及新购买是否会形成另一笔独立订阅。

## 续费与取消

在原购买渠道的订阅管理入口查看续费状态、日期、金额和取消选项。取消前阅读页面对权益结束时间的说明，完成后保存确认记录。

仅退出登录或删除应用不能作为取消完成的凭据。应以订阅管理页面显示的状态为准。

## 退款与账单问题

退款资格、办理入口和到账时间，以订单所属渠道及适用规则为准。取消续费和申请退款分别核对，不把其中一项当成另一项已完成。

处理问题时准备：

- 购买渠道与订单号；
- 付款日期、金额和币种；
- 当前套餐状态；
- 升级或取消的操作时间；
- 相关错误提示和收据。

通过购买渠道或官方支持入口查询，按提示提交必要资料。不要公开完整卡号、验证码、密码、登录令牌或未处理的账单截图。

## 付款失败或权益未显示

| 现象 | 排查顺序 |
| --- | --- |
| 银行卡付款失败 | 检查资料、余额或额度，再向发卡行确认交易限制 |
| 应用内没有目标套餐 | 检查当前账户和可用入口，不购买其他套餐来试探能否解锁 |
| 已付款但套餐未变化 | 核对订单是否完成、ChatGPT 账户是否正确，再联系支持 |
| 商店提示购买关联其他账户 | 检查原购买时使用的 ChatGPT 登录方式和账户 |
| 出现两笔扣款 | 分别核对订单号、渠道、日期和订阅状态 |
| 退款未到账 | 查看处理状态、原支付方式及渠道给出的预计时间 |

排查时一次处理一个问题，保留每一步的结果。不要通过重复下单解决账户关联或权益同步问题。

## 账号与网络

保管好登录凭据和付款资料；收到验证或安全提示时，阅读具体要求并通过可信入口处理。

连接失败时，分别检查网络、应用版本、账户状态和服务提示。购买 VPS、切换地区、修改语言或时区不应作为订阅付款的准备步骤。

本指南不对特定 IP、设备数量、首周用量或所谓模型“提智”设置提供承诺。使用额度及功能状态以账户内显示和官方说明为准。
